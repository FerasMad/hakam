# Data

The dataset is not stored in this repository.

## SoccerNet-MVFoul

3,901 foul incidents, 500 matches, multiple camera angles per incident,
annotated across 10 properties by a professional referee.

**Access requires signing a data agreement.** Request access at:
<https://github.com/SoccerNet/sn-mvfoul>

Place the downloaded files here. Everything in this directory except this
README is gitignored.

## Laws of the Game

The Arabic edition of the IFAB Laws of the Game is used as the retrieval corpus.
Store the extracted text under `laws/`.

**Before relying on it:** confirm the PDF has a real text layer rather than
scanned images. Open it and try selecting a paragraph.
